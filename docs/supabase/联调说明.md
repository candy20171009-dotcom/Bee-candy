# Supabase 联调说明

## 1. 环境变量

在项目根目录创建 `.env.local`：

```bash
DATA_SOURCE=supabase
NEXT_PUBLIC_SUPABASE_URL=https://<project-ref>.supabase.co
SUPABASE_SERVICE_ROLE_KEY=<service-role-key>
```

## 2. 建表

在 Supabase SQL Editor 依次执行：

1. `docs/supabase/schema.sql`
2. `docs/supabase/seed-dividend-sample.sql`（可选）

## 3. 联调检查

启动项目：

```bash
npm run dev
```

打开以下接口验证：

- `GET /api/health/supabase`
- `POST /api/demo-request`
- `GET /api/dividend?insuranceCompany=Bee%20Life`

## 4. 期望结果

1. `GET /api/health/supabase` 返回 `connected: true`
2. 提交预约后返回 `requestId`
3. 查询接口按条件返回真实库数据

## 5. 常见问题

1. `CONFIG_MISSING`：检查 `.env.local` 是否存在且变量名正确
2. `SUPABASE_REQUEST_FAILED`：确认 `service role key` 与 URL 对应同一项目
3. 查询为空：确认 `dividend_rates` 表已导入样例数据

# BeeFintech Phase 1 测试说明

## 环境

- Node.js 20+
- npm

## 启动

```bash
npm install
npm run dev
```

## 手动测试清单

1. 首页加载
- 访问 `/`
- 检查品牌主张、服务能力、AI 展示区与 CTA 正常显示
- 检查移动端宽度下无明显遮挡

2. 预约演示提交流程
- 访问 `/demo`
- 正常填写提交，确认出现成功提示
- 清空联系方式与邮箱后提交，确认出现校验失败提示

3. 分红查询流程
- 访问 `/dividend-tool`
- 输入保险公司 `Bee Life` 查询，确认有结果
- 输入不存在条件查询，确认展示“暂无匹配數據”

4. API 基础验证
- `POST /api/demo-request` 返回 `success: true/false`
- `GET /api/dividend` 返回 `items` 与 `total`

## 已知限制

- 本轮使用 mock 数据，不代表正式生产库
- AI 展示区为可替换占位版本，非最终动态演示

# BeeFintech 官网改版 SPEC（APP 并入首页）

## 1. 变更背景

历史版本官网存在独立 `APP` 页面，用户需要额外跳转才能理解完整能力。  
本轮改版目标是将核心业务能力集中到首页展示，减少路径分叉，提升转化效率与功能可见性。

## 2. 当前目标（2026-05-07 最终版）

1. 顶部导航移除 `APP` 菜单项。
2. 首页完成业务闭环能力整合，作为主入口承载核心展示。
3. 保持 `安全 / 分红查询 / 预约演示` 三个功能页可正常访问与使用。
4. 支持中繁 / 中简 / 英文三语切换，并保证四个页面文案与字体映射正确。
5. 分红查询保持 2022 数据口径的查询闭环能力。

## 3. 范围定义

### 3.1 本期包含

1. 首页模块结构重排与文案更新。
2. 首页多语言文案与语言切换入口上线。
3. 六步业务闭环模块改为单排循环滚动展示。
4. 核心升级能力模块卡片信息简化（去小标签、去编号、标题前图标化）。
5. 产品库与 AI 计划书模块按最终顺序展示。

### 3.2 本期不包含

1. 新增后端接口与数据库结构重构。
2. 分红查询多年份切换（当前固定 2022 口径）。
3. 新账号体系/权限体系改造。

### 3.3 锁定区域（仍不改动）

首页 Hero 主视觉与核心品牌表达保持稳定，不做结构性改版：

1. `LIFEBEE APP + CRM` 标识区
2. 主标题（快人一步 / 保險數碼化）
3. 首屏双 CTA（预约演示、分红查询）
4. 首屏右侧业务状态看板

## 4. 信息架构（导航）

### 4.1 当前导航

1. 首页（`/`）
2. 安全（`/security`）
3. 分红查询（`/dividend-tool`）
4. 预约演示（`/demo`）

### 4.2 兼容策略

1. 历史路径 `/app` 仍保留兼容路由。
2. 访问 `/app` 时重定向至 `/#app-collab`（兼容旧链接）。
3. 当前首页已不再展示独立 `APP + CRM 协同能力` 区块内容，`#app-collab` 仅作兼容锚点保留。

## 5. 首页模块结构（当前真实版本）

### 5.1 模块编号与顺序（由上到下）

1. `H1/H2` Hero 首屏区（左文案 + 右看板）
2. `M1` 六步业务闭环区（单排循环滚动）
3. `M2` 核心升级能力区（4 卡）
4. `M3` 全港最全保险产品库区
5. `M4` AI 计划书区（AI • 3分钟建议书）
6. `M5` AI Chatbot 展示区
7. `M6` 底部转化 CTA 区

### 5.2 模块要点

1. `M1` 六步业务闭环：去掉 `HOW IT WORKS` 小标题，卡片排队循环滚动。
2. `M2` 核心升级能力：去掉顶部标签文案与右侧说明，卡片标题前使用图标，不显示序号。
3. `M3/M4` 顺序：当前为“产品库在前，AI 计划书在后”。
4. `M4` 去除红框类冗余文案，仅保留主标题、要点与流程可视化。
5. `M5` 保留四步 AI 交互演示（步骤切换 + 动态面板）。

## 6. 多语言要求（本期新增）

### 6.1 语言范围

1. `zh-Hant`（繁体中文）
2. `zh-Hans`（简体中文）
3. `en`（英文）

### 6.2 覆盖页面

1. 首页（`/`）
2. 安全（`/security`）
3. 分红查询（`/dividend-tool`）
4. 预约演示（`/demo`）

### 6.3 验收规则

1. 切换繁体时，不出现简体文案混入。
2. 切换简体时，不出现繁体文案混入。
3. 英文版本标题、按钮、段落语义完整可读。
4. 顶部语言切换入口稳定可用。

## 7. 分红查询（2022 口径）

### 7.1 数据来源

1. 输入：`人工加入/2022年分紅達成率.xlsx`
2. 清洗结果：`mocks/dividend-rates-2022.json`
3. 当前数据量：447 条

### 7.2 查询交互

1. 筛选字段：
- 保险公司（下拉 + 模糊搜索）
- 产品名称（下拉 + 模糊搜索）

2. 匹配规则：
- 从候选下拉选择产品时：精确匹配
- 手动输入关键词时：模糊匹配

3. 联动逻辑：
- 先选保险公司后，产品候选范围按保司过滤

### 7.3 展示口径

1. 当前结果列：保司、产品、红利类型、货币、2021/2020/2019/2018
2. 已移除字段：数据来源、更新时间

## 8. 验收标准（2026-05-07）

1. 导航中不再出现 `APP` 菜单项。
2. 首页模块顺序与第 5 章保持一致。
3. `M1` 为单排循环滚动，不出现多行错位。
4. `M2` 卡片标题前为图标，不显示序号。
5. `M3` 在 `M4` 之前展示。
6. 四个页面语言切换正确，文案不串语系。
7. `/security`、`/dividend-tool`、`/demo` 功能可用。
8. 分红查询可完成“下拉选择 + 模糊搜索 + 精确匹配”闭环。

## 9. 风险与应对

### 风险 1：历史 `/app` 用户路径与新首页信息不一致

应对：保留 `/app` 兼容跳转，并在首页持续优化核心能力展示层次。

### 风险 2：多语言规模扩大导致文案映射错位

应对：统一文案字典管理，按页面逐项回归检查。

### 风险 3：动画与布局在不同分辨率下发生错位

应对：保持模块化样式规则，针对桌面/移动端分别验收。

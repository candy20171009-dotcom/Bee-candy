## 7. 分红查询 UI（当前实现）

### 7.1 数据与范围

1. 数据来源：`人工加入/2022年分紅達成率.xlsx`
2. 清洗产物：`mocks/dividend-rates-2022.json`
3. 当前记录：447 条

### 7.2 查询控件

1. 保险公司：下拉 + 模糊搜索
2. 产品名称：下拉 + 模糊搜索
3. 联动：先选保司后过滤产品候选
4. 规则：下拉选中产品为精确匹配，手输关键词为模糊匹配

### 7.3 结果区

1. 字段：保司、产品、红利类型、货币、2021/2020/2019/2018
2. 已移除：数据来源、更新时间
3. 状态色：
- `>=100%` 绿色
- `80%~99%` 蓝色
- `<80%` 橙色
- 不适用灰色

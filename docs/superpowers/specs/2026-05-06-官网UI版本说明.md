# BeeFintech 官网 UI 版本说明（2026-05-06）

## 1. 版本目标

本版本将官网统一为浅色 SaaS 视觉体系，在保留首屏核心品牌表达的前提下，强化业务闭环展示、功能分层与转化入口。

## 2. 全局视觉规范

1. 主体风格：浅色蓝调 SaaS
2. 主背景：`#f4f8ff`
3. 主文字：`#132344`
4. 主按钮：蓝紫渐变（`#2d66ff -> #6f76ff`）
5. 卡片样式：白底、浅蓝边框、轻阴影、圆角
6. 交互风格：轻 hover、轻位移动效

## 3. 首页模块结构（自上而下）

1. `H1` 首屏左侧 Hero（锁定区域）
- `LIFEBEE APP + CRM` 标识
- 主标题：快人一步 / 保險數碼化
- 副标题描述
- 双 CTA：预约产品演示 / 体验分红查询工具
- 175+ 采用说明

2. `H2` 首屏右侧看板
- 核心闭环简卡
- 今日同步状态卡
- AI 建议书卡
- 私有部署卡

3. `M1` 六步业务闭环
- 资讯、产品库、投保、新单、保单、介绍费

4. `M2` 2025 核心升级能力
- AI 保单同步
- Eform 无纸化投保
- 合规资料库
- 邀约神器

5. `M3` 三大关键功能
- 预约演示转化
- 分红达成率查询
- AI 能力可视化

6. `M4` AI 展示区
- Step1 输入需求
- Step2 AI 分析与生成
- Step3 输出可跟进结果

7. `M5` 底部转化区
- 预约 Demo
- 进入查询工具

## 6. 分红查询 UI（2022 数据版）

### 6.1 数据口径

1. 数据文件：`人工加入/2022年分紅達成率.xlsx`
2. 清洗输出：`mocks/dividend-rates-2022.json`
3. 当前记录规模：447 条

### 6.2 查询区交互

1. 字段：
- 保險公司（可下拉选择 + 可模糊输入）
- 產品名稱（可下拉选择 + 可模糊输入）

2. 交互规则：
- 先选保司后，产品候选联动过滤
- 选中候选产品：查询按精确匹配
- 手输关键词：查询按模糊匹配

3. 视觉规则：
- 统一单箭头（移除双箭头问题）
- 统一输入框高度、边框、间距

### 6.3 结果区（方案 A）

当前列结构：
1. 保險公司
2. 產品名稱
3. 紅利類型
4. 貨幣類型
5. 2021
6. 2020
7. 2019
8. 2018

已移除列：
1. 數據來源
2. 更新時間

颜色策略：
1. `>=100%` 绿色标签
2. `80%~99%` 蓝色标签
3. `<80%` 橙色标签
4. 不適用灰色标签

## 7. 沟通改版建议格式

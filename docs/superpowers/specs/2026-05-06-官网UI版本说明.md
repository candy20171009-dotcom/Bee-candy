# BeeFintech 官网 UI 版本说明（2026-05-06）

## 1. 版本目标

本版本将官网统一为浅色 SaaS 视觉体系，在保留首屏核心品牌表达的前提下，强化业务闭环展示、功能分层与转化入口。

## 2. 全局视觉规范

1. 主体风格：浅色蓝调 SaaS
2. 主背景：`#f4f8ff`
3. 主文字：`#132344`
4. 主按钮：蓝紫渐变（`#2d66ff -> #6f76ff`）
5. 卡片样式：白底、浅蓝边框、轻阴影、圆角
6. 交互风格：轻 hover、轻位移动效

## 3. 首页模块结构（自上而下）

1. `H1` 首屏左侧 Hero（锁定区域）
- `LIFEBEE APP + CRM` 标识
- 主标题：快人一步 / 保險數碼化
- 副标题描述
- 双 CTA：预约产品演示 / 体验分红查询工具
- 175+ 采用说明

2. `H2` 首屏右侧看板
- 核心闭环简卡
- 今日同步状态卡
- AI 建议书卡
- 私有部署卡

3. `M1` 六步业务闭环
- 资讯、产品库、投保、新单、保单、介绍费

4. `M2` 2025 核心升级能力
- AI 保单同步
- Eform 无纸化投保
- 合规资料库
- 邀约神器

5. `M3` 三大关键功能
- 预约演示转化
- 分红达成率查询
- AI 能力可视化

6. `M4` AI 展示区
- Step1 输入需求
- Step2 AI 分析与生成
- Step3 输出可跟进结果

7. `M5` 底部转化区
- 预约 Demo
- 进入查询工具

## 4. 导航与功能页状态

顶部导航当前包含：
1. 首页（`/`）
2. 安全（`/security`）
3. APP（`/app`）
4. 分红查询（`/dividend-tool`）
5. 预约演示（`/demo`）

对应页面已统一为同一视觉体系：
1. 安全页：能力卡 + 术语卡 + 演示 CTA
2. APP 页：能力卡 + 角色价值卡 + 演示 CTA
3. 分红页：浅色 Hero + 查询筛选卡 + 结果表格卡
4. 预约页：浅色 Hero + 表单卡（统一输入框与按钮样式）

1. 首页：`app/page.tsx`

3. 头部导航：`components/site/site-header.tsx`
4. 页脚：`components/site/site-footer.tsx`
5. 安全页：`app/security/page.tsx`
6. APP 页：`app/app/page.tsx`
7. 分红页：`app/dividend-tool/page.tsx`

9. 分红结果：`components/dividend/dividend-results.tsx`

## 6. 沟通改版建议格式

建议后续按“模块编号 + 改动类型 + 目标效果”提需求，例如：

`改 M2（视觉）：4 张能力卡背景再浅一点，边框更明显；H1 保持不变。`

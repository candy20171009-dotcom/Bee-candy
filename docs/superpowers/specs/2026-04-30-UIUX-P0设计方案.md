# BeeFintech UI/UX P0 设计方案（官网风格贴近版）

## 1. 设计目标

1. 用户在首页 10 秒内理解：BeeFintech 是完整保险经纪业务平台。
2. 视觉语言贴近官网（蓝色科技感 + 大留白 + 模块化图文）。
3. 强化“PC + APP 协同 + 安全可信”两条采购决策关键信号。

## 2. 视觉方向（对齐官网）

- 风格关键词：科技蓝、清晰、可信、功能导向。
- 色彩依据：来自官网 `index.css` 真实色值。

主色与语义色：

1. `#1275FD`：主品牌蓝（高亮、导航激活、关键链接）
2. `#2385F8`：按钮渐变起点
3. `#11B7FA`：按钮渐变终点
4. `#2C3033`：深色区背景（页脚）
5. `#444`：标题主文字
6. `#333`：正文主文字
7. `#888`：说明文字
8. `#D8D8D8`：浅边框
9. `#FFF`：主底色

按钮标准：

- 主按钮：`linear-gradient(-90deg, #2385F8 3%, #11B7FA 100%)`
- 次按钮：白底蓝边（`#1275FD`）

## 4. 模块设计规范

## 模块 A：全链条业务流程展示（Homepage）

### 布局

- 桌面端：左 30%（步骤导航）+ 右 70%（步骤详情）
- 移动端：顶部横向步骤条 + 下方详情卡

### 交互

1. 默认高亮第 3 步“方案生成”
2. 点击步骤后详情区 200ms 淡入切换
3. 当前步骤显示蓝色强调条（`#1275FD`）与圆角数字徽章

### 内容结构（每步）

1. 场景说明
2. 关键动作（3 条）
3. 输出结果（2 条）
4. 适用角色标签（顾问 / 团队长 / 运营）

## 模块 B：APP 协同能力展示（Homepage）

### 布局

- 左：PC 端动作
- 中：APP 端承接动作
- 右：协同收益卡

### 交互

1. Hover 任一动作，联动高亮对应收益
2. CTA 跳转 `/app`
3. 收益值使用蓝色标签或蓝底白字数字卡

## 模块 C：安全能力页面（`/security`）

### 页面结构

1. Hero：企业级安全承诺
2. 五大能力卡（2 列，移动端 1 列）
3. 术语解释区（ACL、审计日志、传输加密、存储加密）
4. CTA：预约安全能力演示

### 视觉规则

1. Hero 使用蓝色渐变背景
2. 卡片白底浅灰边，hover 转浅蓝边
3. 术语区使用浅灰底块分组展示

## 模块 D：APP 页面（`/app`）

### 页面结构

1. Hero：移动协同价值
2. 6 项能力卡网格
3. 角色场景区（顾问 / 团队长 / 运营）
4. CTA：预约演示

能力卡：

1. 产品库
2. 产品对比
3. 保费试算
4. 客户管理
5. 消息提醒
6. 名片分享

## 5. Token 与组件规范（官网贴近）

推荐 CSS 变量：

```css
:root {
  --brand-primary: #1275fd;
  --brand-grad-start: #2385f8;
  --brand-grad-end: #11b7fa;
  --text-title: #444444;
  --text-body: #333333;
  --text-muted: #888888;
  --surface-base: #ffffff;
  --surface-muted: #f7f9fc;
  --footer-dark: #2c3033;
  --border-soft: #d8d8d8;
}
```

组件规则：

1. 卡片圆角：`12-16px`
2. 卡片边框：`1px solid var(--border-soft)`
3. 主按钮：蓝色渐变 + 胶囊（40px 高）
4. 导航滚动后：白底、深字、蓝色激活态
5. 标题用 `#444`，正文用 `#333`，说明用 `#888`

## 6. 可访问性与体验要求

1. 所有流程步骤可键盘访问（Tab/Enter）
2. 状态变化有文本提示，不仅靠颜色
3. 移动端最小点击区域 >= 40px
4. 文本与背景对比度保持可读

## 7. 前端落地顺序

1. 先完成结构骨架与交互（流程/APP/security）
2. 全站主题切换到官网蓝色系 token
3. 填正式文案与图标
4. 细化动效与移动端排版

## 8. UI/UX 验收

1. 首页 1-2 屏内能看到“流程 + APP + 预约入口”
2. `/security` 与 `/app` 风格与官网蓝色体系一致
3. 手机端无溢出、无重叠、无不可点击
4. 主按钮、导航、标题色调统一为官网蓝系

# BeeFintech 官网升级执行规划（Phase 1）

## 目标

在第一轮完成可运行、可演示、可扩展的官网基础框架，覆盖首页、预约演示与分红查询闭环。

## 本轮交付

1. Next.js + TypeScript 分层架构
2. 首页（品牌、服务能力、AI 能力展示区）
3. 预约演示表单（提交、校验、反馈）
4. 分红达成率查询工具（筛选、结果、空态）
5. Route Handlers + mock 数据源闭环
6. 基础运维与协作文档

## 实施节奏

1. 工程初始化与目录搭建
2. 领域模型与用例编排
3. 数据仓储与 API 对接
4. 页面与交互实现
5. 本地运行与手工验证

## Phase 2 预留

1. mock 切 Supabase
2. AI 展示区关键帧替换与动效升级
3. 自动化测试与部署增强
